# 指纹测试 🔐

一个用手机指纹解锁的测试小应用，从最初只有指纹识别，一路迭代到现在支持 **PIN/密码、震动反馈、锁声音效、重置按钮**，并且**界面支持 30 种语言**（跟随手机系统语言自动切换）。

- 包名：`com.dudu.fingertest`
- 最新版本：v1.11
- 支持：指纹 / 面部（生物识别）+ PIN/密码
- 权限：仅 `USE_BIOMETRIC`（生物识别）、`VIBRATE`（震动）

## 多语言支持（v1.11）

应用名和全部界面文案都会跟随手机的系统语言自动切换，已内置以下 30 种语言：

简体中文、繁体中文、English、日本語、한국어、Français、Deutsch、Español、Português、Русский、Italiano、Nederlands、Polski、Türkçe、Bahasa Indonesia、Tiếng Việt、ไทย、हिन्दी、العربية、Bahasa Melayu、Українська、Čeština、Ελληνικά、Svenska、Dansk、Suomi、Magyar、Română、עברית、Norsk

> 如果手机系统不在列表里，会回退到默认的简体中文。以后想加更多语言，在 `res/values-语言/strings.xml` 里加一份翻译再打包就行。

## 怎么装

1. 下载对应版本的 `.apk` 文件（建议用最新版 `1.11/1.11.apk`）
2. 手机上允许"安装未知来源应用"
3. 打开 APK 安装即可

> 所有版本都用同一个签名（证书 CN=DUDU），所以新版本可以直接覆盖安装旧版本，不会丢数据。

## 关于源码

本项目在手机上开发，原始工程不在身边，所以仓库里的源码是从最新版 APK（v1.11）反编译来的：

- **源码-java/**：接近原始写法的 Java 代码，适合阅读和学习，主逻辑在 `sources/com/dudu/fingertest/FingerprintActivity.java`
- **源码-smali/**：用 apktool 完整反编译的工程（AndroidManifest.xml + smali + 资源），可以用下面的命令重新打包成 APK：

```bash
apktool b 源码-smali -o rebuilt.apk
```

> 如果想看各版本的差异，可以对比不同版本 APK 反编译后的 `FingerprintActivity.smali`。
