# 指纹测试 🔐

一个用手机指纹解锁的测试小应用，从最初只有指纹识别，一路迭代到现在支持 **PIN/密码、震动反馈、锁声音效、重置按钮**。

- 包名：`com.dudu.fingertest`
- 最新版本：v1.10
- 支持：指纹 / 面部（生物识别）+ PIN/密码
- 权限：仅 `USE_BIOMETRIC`（生物识别）、`VIBRATE`（震动）

## 怎么装

1. 下载对应版本的 `.apk` 文件（建议用最新版 `1.10/1.10.apk`）
2. 手机上允许"安装未知来源应用"
3. 打开 APK 安装即可

> 所有版本都用同一个签名（证书 CN=DUDU），所以新版本可以直接覆盖安装旧版本，不会丢数据。
